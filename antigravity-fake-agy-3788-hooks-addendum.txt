3. Explicit limits of d744d187 (kept, not fixed)
L1 Schema check limit. fake-agy.test.ts checks each message the fake writes against the vendored ACP schema only at the top level: the method exists on the right side, the definition's top-level required fields are present, update kinds are in ACP_SESSION_UPDATE_KINDS, and stop reasons are in the StopReason enum. It is not full JSON Schema validation. Nested shapes, field types and nested enums (tool call content, config option variants, permission options, auth method variants) are not validated.
L2 argv verbatim and report privacy. report.argv records every agy argument verbatim, and the TUI banner prints argv to stderr. Everything else in the report is reduced: env is an allowlist, the hook nonce and credentials are recorded by presence or name only, and MCP env and header values are stripped. A caller that put a secret on the command line would have it recorded. Clubhouse's design passes no secrets on argv, and the tests use only synthetic arguments.
L3 Hook grandchild cleanup. On a handler timeout the fake kills only its direct child (the shell) and stops waiting at once. A grandchild started by the handler command can survive and keep running until it exits by itself. The fake does not kill the process tree.
L4 run5 seal gap. Run5 (gate START 2026-11-24T04:36:03Z, END 04:36:08Z, rc=0) recorded head and tree in run5-admission.txt but took no clean git status --porcelain seal at that moment.
