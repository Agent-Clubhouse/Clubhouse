# Chat E2E media

Tiny media files for the rich chat E2E specs (`e2e/chat-rich`, plan in [docs/testing/chat-e2e-plan.md](../../docs/testing/chat-e2e-plan.md)). Every file is generated by `scripts/chat-fixtures/make-media.mjs`, from code or from ffmpeg's built-in test sources, so there is nothing to license.

| File | What it is |
|---|---|
| `tiny.png` | 24 × 16 RGB gradient |
| `two-pages.pdf` | Two Letter pages, "Page 1" and "Page 2" in Helvetica |
| `tone.wav` | 0.5 s, 440 Hz sine, 8 kHz mono 8-bit PCM |
| `clip.webm` | 1 s of ffmpeg's `testsrc` pattern (64 × 48, VP8) with a 440 Hz tone (Opus) |

Regenerate them with:

```sh
node scripts/chat-fixtures/make-media.mjs --ffmpeg "$(command -v ffmpeg)"
```

PNG, PDF and WAV come out byte-for-byte the same every time. The WebM depends on the ffmpeg build, so leave out `--ffmpeg` to keep the committed one. Any ffmpeg with libvpx and libopus works; without a system ffmpeg, `pip install imageio-ffmpeg` in a throwaway venv provides one.

`chat-script.test.ts` checks each file sniffs as its type and stays under 16 KB.
