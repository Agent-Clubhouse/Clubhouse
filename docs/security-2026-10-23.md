# October 2026 dependency security pass

**Follow-up:** the newer [Electron 45 / residual tooling ledger](electron45-security-2026-10-23.md) supersedes the runtime selection and residual audit counts below; earlier validation remains historical evidence.

Baseline: main `8e0903616ee45bff75c04f9bb62dc35feafce7f2`. Checked 2026-10-23.
This patch is a partial remediation, **not a release clearance**. CI's Node pin is
tracked separately in #2426; it does not change Electron's embedded Node.

Source-map inspection of the built main chunks finds node-forge, but no npm
Express, qs, fast-uri, proxy-addr, tar, extract-zip or Undici modules. This is a
bounded bundle check, not an assertion about all opaque SDK internals or child
CLIs. Host/agent runtimes have their own provenance and are not patched here.

## Validation and binary provenance

- Host validation used Node 24.22.1 / npm 11.19.1; clean `npm ci` passed.
- Typecheck and lint passed (0 errors; existing warning backlog).
- Full unit/component/integration suite: 789 files passed, 4 skipped;
  18,178 tests passed, 37 skipped. Initial sandbox run could not bind loopback;
  the complete rerun with local process/network access passed.
- `npm run package`: macOS ARM64 build and all six hardened-fuse assertions passed.
- Startup/navigation E2E: 20 passed; Annex authentication/lifecycle: 6 passed.
- `e2e/runtime-security.spec.ts`: embedded version reporting, self-signed TLS
  rejection, per-request CA acceptance and valid Brotli fetch decoding passed.
  No external accounts, real agent starts, persistent pairing or system trust
  changes were used. These checks do not certify the outstanding CVEs fixed.

Executed official runtime: Electron **43.8.3**, Node **24.22.0**, Chromium
**150.0.7871.250**, Undici **7.29.1**, Brotli **1.2.0**.
The packaged ARM64 Electron Framework is 196,510,528 bytes. Compared byte for byte
with that executed official framework, the only difference is the expected fuse
wire at offset 152,939,770: `101100` → `010011` (six bytes).

**Packaged launch validation completed on 2026-10-23 for commit b96213e9:**
the original unsigned output was preserved, and the user authorized ad-hoc
signing of an isolated copy only. The actual packaged executable started with
`app.isPackaged === true`, Electron 43.8.3, Node 24.22.0 and Chromium
150.0.7871.250. Strict deep signature verification passed; all six hardened
fuses and the app.asar hash were unchanged. The disposable profile was removed
and the test process exited with code 0.

Packaged Annex rejected an unauthenticated request and wrong PIN, then accepted
a temporary pairing and delivered protocol v2 snapshots across connection and
reconnection over TLS with an explicit test CA and exact certificate pin. The
server was disabled before exit. Packaged marketplace fetched the official
registry over HTTPS, decoded an empty benign Brotli fixture and failed on an
untrusted local HTTPS fixture. No plugins or real agents were started. This
proves the marketplace decoder path exists, not that the Brotli CVE is fixed.

Ad-hoc validation is not production signing/notarization validation. Packaged
updater download/apply/relaunch and Chromium TLS behavior remain unverified.
The expanded dependency sweep and its separate validation are recorded in
[dependency-sweep-2026-10-23.md](dependency-sweep-2026-10-23.md).

Release recommendation: hold release pending a stable Electron with verified
complete applicable Node fixes and normal reviewed, CI-green landing. PR
creation was denied with `403 FORBIDDEN: Resource not accessible by integration`;
no alternate write route was used. Main remained at the baseline above.
