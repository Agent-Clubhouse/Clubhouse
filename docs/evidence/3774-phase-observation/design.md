## Durable, bounded, payload-free output

Each begin/end and abort/final snapshot is a small `process.stderr.write` line prefixed `CLUBHOUSE_MANAGED_PHASE_V1 `. Emit begin before native calls: a synchronous stall can leave a durable last-started phase even if the timer cannot fire yet. Use a monotonic clock, relative offsets, static phase labels, sequence numbers, completion/throw booleans and active-phase elapsed intervals. Retain the abort snapshot separately from the final snapshot so later cleanup cannot erase evidence that work was unfinished at the deadline.

The annotation contains the bounded event history and both snapshots. Installed Vitest 4.1.12's public context API provides `signal`/`annotate`; inspected JUnit code serializes annotations as testcase properties without reporter configuration. This is source-level feasibility, **not executed failure-channel proof**. Raw stderr is the early channel; the existing uploaded JUnit artifact is the final durable channel when hooks/reporting finish. A killed worker/job may have only partial raw transitions: no final annotation or duration is invented.

The fixed phase set is `beforeEach`, `seed.copy`, `builtins.ensure`, `body`, `git.init`, `git.add`, `git.async`, `delivery`, `resolve` and `grant.cleanup`. Transition fields are `seq`, `event` (`begin`/`end`), `phase`, `offsetMs` and `threw` on an end. Snapshot fields are `event` (`abort`/`final`), `offsetMs`, `aborted` and `active` entries containing only `beginSeq`, `phase`, `startMs`, `elapsedMs`. Annotation keys are `version`, `platform`, `node`, `transitions`, `abort`, `final`, `overflow`, `droppedTransitions`; absent abort is explicitly `null`. A raw post-annotation `published` event reports its `offsetMs`/`elapsedMs` separately. Completion means a scope returned/child closed, not Git success or grant delivery.

The allowlist is the fixed diagnostic version, `process.platform`, `process.version`, static phase/event labels, finite relative numbers and booleans. Never serialize native arguments/options, cwd, paths, environment, project/agent/task identities, contents, stdout/stderr, errors/stacks/reasons or child identifiers. Cap retained transitions at 32; any overflow must be explicit, not reported as a complete trace. Publish elapsed time is diagnostic overhead, not delivery/body time. Both inline logging overhead and changed scheduling may affect this new observation; even a green run does not retrospectively prove a flake or remove the original failure.
