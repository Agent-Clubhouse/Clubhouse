## Descriptor and failure boundary

Windows reused-page preparation now opens O_RDWR without create/truncate/append,
plus the existing nonblocking/no-follow flags where available. It opens before
content validation, so initial identity, bounded read/digest, file sync and final
descriptor/path checks use one exact handle. There is no second reopen whose
identity/content must be guessed. Ordinary reads remain O_RDONLY everywhere;
POSIX reused-file sync remains read-only as approved283. No format migration or
Windows settings switch is introduced.

Permission/access/sync errors refuse; no EPERM/EACCES durability downgrade is
added. A private initial-absence error distinguishes the first lstat ENOENT
from later IO errors. Only that initial absence permits a new immutable write.
In particular, ENOENT from validated-file sync cannot silently authorize
replacement. Descriptor close remains in finally. Directory-flush observations
and their narrow native limitations are unchanged, separate from file sync.
