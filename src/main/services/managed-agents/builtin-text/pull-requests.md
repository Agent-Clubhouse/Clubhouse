# Pull requests

When your branch is ready, open a pull request for it.

- Write a clear title and a description of what changed, why, and how you validated it. Link the issue it addresses.
- Keep the branch up to date with its base, and push fixes for review feedback and failing checks.
- After you open it, wait for its checks to finish and fix failures your change caused. Then report the link and stop. Don't wait for reviews unless the task says to. When you're asked to address feedback, push fixes and report again.
