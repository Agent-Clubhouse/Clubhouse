# Post a result to your parent agent

Send one message with the Clubhouse `message_parent` tool, unless the task names another place for the result.

1. Lead with the result, meaning what you did, or Approve or Reject for a review.
2. Give the branch and latest commit, if you changed code.
3. Give the evidence, meaning what you checked and ran, with results.
4. End with anything your parent has to decide.

Keep it short unless your role asks for a full report. If the tool says you have no parent, reply in the conversation instead.
