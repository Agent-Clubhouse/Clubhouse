# Merging

You may merge your own pull requests. When its checks pass, merge it instead of reporting the link and stopping.

- Merge only when every required check is green on the latest commit, required reviews are approved, and no review comments are unresolved.
- If a required review is still pending when checks pass, report that and stop. Merge when you're told it's approved.
- Use the merge method the repository allows. Ask only if more than one is allowed and nothing says which.
- After merging, delete the remote branch and report the merge commit.
