# Display and themes

Open Settings with `⌘,` and pick **Display & UI**.

## Color theme

Pick a theme and it applies right away, terminals included.

| Theme | Style |
|-------|-------|
| **Catppuccin Mocha** | Dark, warm pastels (the default) |
| **Catppuccin Latte** | Light, soft pastels |
| **Solarized Dark** | Dark, precise contrast |
| **Terminal** | Dark, green on black |
| **Nord** | Dark, cool blues |
| **Dracula** | Dark, purples and pinks |
| **Tokyo Night** | Dark, deep blues |
| **Gruvbox Dark** | Dark, warm earth tones |
| **Cyberpunk** | Dark, neon |

## Theme collections

More collections come built in. Themes are dark unless marked light.

| Collection | Themes |
|------------|--------|
| **Gradients** | Aurora, Canyon, Daybreak (light), Mist (light). Designed around their background gradients |
| **Fall** | Maple (light), Harvest (light), Pumpkin Spice (light), Amber Forest (light), Twilight Ember |
| **Winter** | Frost (light), Evergreen (light), Northern Lights, Snowfall (light), Polar Night |
| **Spring** | Cherry Blossom (light), Spring Meadow (light), Wisteria (light), Daffodil (light), Moonlit Garden |
| **Summer** | Sunset Beach (light), Ocean Breeze (light), Tropical (light), Golden Hour (light), Midnight Swim |
| **Ocean** | Coral Reef (light), Tide Pool (light), Pacific (light), Deep Sea, Abyssal |
| **Tech Modern** | Redmond, Mountain View (light), Cupertino (light), AI Lab (light), Seattle |
| **Neon** | Neon Cyberpunk, Synthwave, Neon Tokyo, Electric, Vaporwave (light) |

These started as Workshop theme packs. Some of their colors were adjusted so text, notices and code stay readable. If you used one from an installed pack, pick it again here.

Plugins can add more themes, which show up in the same list.

**Theme gradients & fonts** lets a theme use its own font families and background gradients, including themes from plugins. Turn it off to keep every theme to its colors and the standard fonts.

Every theme includes terminal colors: the 16 ANSI colors, the cursor and the selection. Open terminals update when you switch.

## Idle projects

**Idle projects** sets how long an unpinned project can go without activity before it folds into the idle row at the bottom of the sidebar. Activity means an agent ran or woke, a quick agent started, or you opened one of the project's tabs. Choose **Never** to keep every project in the list.

## Sidebar

Drag the sidebar's right edge to change its width, and press `⌘B` to hide or show it.
