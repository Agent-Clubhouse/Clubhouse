# Display and themes

Open Settings with `⌘,` and pick **Display & UI**.

## Color theme

Pick a theme and it applies right away, terminals included.

| Theme | Style |
|-------|-------|
| **Catppuccin Mocha** | Dark, warm pastels (the default) |
| **Catppuccin Latte** | Light, soft pastels |
| **Solarized Dark** | Dark, precise contrast |
| **Terminal** | Dark, green on black |
| **Nord** | Dark, cool blues |
| **Dracula** | Dark, purples and pinks |
| **Tokyo Night** | Dark, deep blues |
| **Gruvbox Dark** | Dark, warm earth tones |
| **Cyberpunk** | Dark, neon |

Plugins can add more themes, which show up in the same list.

Every theme includes terminal colors: the 16 ANSI colors, the cursor and the selection. Open terminals update when you switch.

## Idle projects

**Idle projects** sets how long an unpinned project can go without activity before it folds into the idle row at the bottom of the sidebar. Activity means an agent ran or woke, a quick agent started, or you opened one of the project's tabs. Choose **Never** to keep every project in the list.

## Sidebar

Drag the sidebar's right edge to change its width, and press `⌘B` to hide or show it.
