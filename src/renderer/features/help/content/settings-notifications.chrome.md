# Notifications and badges

Clubhouse can tell you about agent activity while you're in another app. Open Settings with `⌘,` and pick **Notifications & alerts**.

## Desktop notifications

**Desktop notifications** turns them all on or off. Under **Notify me when**, each event has its own switch:

| Switch | Notifies when |
|--------|---------------|
| **An agent needs permission** | An agent is waiting for approval. Leave this on so agents don't sit blocked. |
| **An agent stops** | An agent has finished running |
| **An agent is waiting for input** | An agent is idle and waiting on you |
| **A tool call fails** | One of an agent's tool calls errors |
| **An agent asks for me** | An agent calls the `notify_user` tool |

**Test notification** has a **Send test** button, so you can check your system settings. If nothing appears on macOS, open **System Settings > Notifications > Clubhouse** and allow them.

Inside Clubhouse, agents waiting on you are always listed under **Needs you** at the top of the sidebar, whatever these switches say.

## Badges

Badges are the counts on title-bar tabs and the Dock icon.

| Setting | Controls |
|---------|----------|
| **Show badges** | All badges |
| **Plugin badges** | Counts that plugins add to their tabs |
| **Clear all badges** | Its **Clear** button removes every badge now |

Each project can override these. Open the project's settings and pick **Notifications & alerts**. Each badge setting there can be **Global**, which follows the app setting, or **On** or **Off** for that project.

## Dock badge

On macOS, the Dock icon shows how many items are waiting, such as permission requests. It clears as you deal with them.
