# Notifications and badges

Clubhouse can tell you about agent activity while you're in another app. Open Settings with `⌘,` and pick **Notifications & alerts**.

## Desktop notifications

**Enable notifications** turns them all on or off. Below it, each event has its own switch:

| Event | Notifies when |
|-------|---------------|
| **Permission needed** | An agent is waiting for approval. Leave this on so agents don't sit blocked. |
| **Agent stopped** | An agent has finished running |
| **Agent idle** | An agent is waiting for input |
| **Agent error** | A tool call fails |
| **Agent requested attention** | An agent asks for you with the `notify_user` tool |

**Send test** sends a notification so you can check your system settings. If nothing appears on macOS, open **System Settings > Notifications > Clubhouse** and allow them.

Inside Clubhouse, agents waiting on you are always listed under **Needs you** at the top of the sidebar, whatever these switches say.

## Badges

Badges are the counts and dots on title-bar tabs and the Dock icon.

| Setting | Controls |
|---------|----------|
| **Enable badges** | All badges |
| **Plugin badges** | Badges that plugins set on their tabs |
| **Clear all badges** | Removes every badge now |

Each project can override these. Open the project's settings and pick **Notifications & alerts**: every setting there can follow the app value, or be on or off for that project.

## Dock badge

On macOS, the Dock icon shows how many items are waiting, such as permission requests. It clears as you deal with them.
