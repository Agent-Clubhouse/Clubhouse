# Keyboard shortcuts

On Windows and Linux, use `Ctrl` in place of `⌘`.

You can change any of these in **Settings > Keyboard shortcuts**. A binding you set there wins over a default; if it clashes with one, the default is left unbound and the page shows the conflict.

## General

| Shortcut | Action |
|----------|--------|
| `⌘K` | Open the command palette |
| `⌘,` | Open or close Settings |
| `⇧⌘/` | Open or close Help |
| `⌘B` | Show or hide the sidebar |

`⌘K` works even while you're typing in a field.

## Tabs and agents

| Shortcut | Action |
|----------|--------|
| `⌘1` | Agents tab |
| `⌘2` to `⌘9` | The other title-bar tabs, in order |
| `⌥⌘1` to `⌥⌘9` | Switch to agent 1 to 9, in sidebar order |
| `⇧⌘N` | New quick agent: opens the active project's start page with the box focused |
| `⇧⌘T` | Focus the active agent's CLI view, if typing stops reaching it |

There are no shortcuts to switch projects by number. Use `⌘K` and type `/` with part of the project name.

## Projects

| Shortcut | Action |
|----------|--------|
| `⇧⌘O` | Add a project |
| `⇧⌘W` | Close the active project |

## Command palette prefixes

Open `⌘K`, then start with:

| Prefix | Finds |
|--------|-------|
| `@` | Agents |
| `/` | Projects |
| `#` | Canvases |
| `>` | Commands and settings |

## Plugins

Plugins can add their own shortcuts, such as `⇧⌘F` to search files in the Files tab. They are listed with the rest in **Settings > Keyboard shortcuts**.

## Notes

- When an agent's CLI view has focus, typing goes to the agent. App shortcuts like `⌘K` still work.
- Changes to shortcuts apply right away.
