# Display & Themes

Customize how Clubhouse looks: themes, terminal colors, and display preferences.

## Changing Your Theme

**Settings > Display & UI** — Select a theme. Applied immediately, no restart needed.

## Built-in Themes

| Theme | Style |
|-------|-------|
| **Catppuccin Mocha** | Dark, warm pastels *(default)* |
| **Catppuccin Latte** | Light, soft pastels |
| **Solarized Dark** | Dark, precision contrast |
| **Terminal** | Dark, green-on-black CRT |
| **Nord** | Dark, arctic blue tones |
| **Dracula** | Dark, vivid purples and pinks |
| **Tokyo Night** | Dark, cool blue tones |
| **Gruvbox Dark** | Dark, warm retro earth tones |
| **Cyberpunk** | Dark, neon-soaked futuristic |

## Theme collections

Seven more collections come built in, five themes each. Themes are dark unless marked light.

| Collection | Themes |
|------------|--------|
| **Fall** | Maple (light), Harvest (light), Pumpkin Spice (light), Amber Forest (light), Twilight Ember |
| **Winter** | Frost (light), Evergreen (light), Northern Lights, Snowfall (light), Polar Night |
| **Spring** | Cherry Blossom (light), Spring Meadow (light), Wisteria (light), Daffodil (light), Moonlit Garden |
| **Summer** | Sunset Beach (light), Ocean Breeze (light), Tropical (light), Golden Hour (light), Midnight Swim |
| **Ocean** | Coral Reef (light), Tide Pool (light), Pacific (light), Deep Sea, Abyssal |
| **Tech Modern** | Redmond, Mountain View (light), Cupertino (light), AI Lab (light), Seattle |
| **Neon** | Neon Cyberpunk, Synthwave, Neon Tokyo, Electric, Vaporwave (light) |

These started as Workshop theme packs. Some of their colors were adjusted so text, notices and code stay readable. If you used one from an installed pack, pick it again here.

**Theme gradients & fonts** lets a theme use its own font families and background gradients, including themes from plugins. Turn it off to keep every theme to its colors and the standard fonts.

## Terminal Colors

Each theme includes a complete terminal color scheme (16 ANSI colors, cursor, selection highlight). Terminal colors update immediately across all open sessions when you switch themes.
